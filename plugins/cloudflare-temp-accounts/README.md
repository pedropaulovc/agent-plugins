# cloudflare-temp-accounts plugin

Provides the `/cloudflare-temp-accounts` skill: provisions a Cloudflare account through Wrangler's temporary-account flow, claims it immediately in the correct headed browser session, applies the final environment name, and isolates the Wrangler auth profile.

## Codex and OpenCode support

Works in Claude Code, Codex, and OpenCode. Use `$cloudflare-temp-accounts` in Codex or `/cloudflare-temp-accounts` in Claude Code/OpenCode.
